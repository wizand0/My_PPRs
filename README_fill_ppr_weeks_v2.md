# fill_ppr_weeks_v2.py

Скрипт для автоматического переноса номеров недель ТО‑1…ТО‑4 с общего
годового графика (лист **«ППР»**) на отдельные технологические карты
(листы-разделы вроде «Электрощиты», «Вентиляция 1 оч.» и т.п.) в одной
и той же книге Excel.

## Зачем он нужен

При ручном заполнении техкарт легко ошибиться: забыть неделю, перепутать
раздел, оставить старые данные от прошлого года. Этот скрипт убирает
ручной перенос данных полностью — недели вписываются программно на
основе того, что реально стоит на листе «ППР», и при малейшем
несоответствии структуры скрипт не молчит, а выводит предупреждение.

**Что делает:**
- Читает лист «ППР», определяет, к какому разделу оборудования
  относится каждая строка, и собирает по каждому разделу список недель
  для ТО‑1, ТО‑2, ТО‑3 и ТО‑4.
- Проставляет год (из ячейки `C1` листа «ППР») в ячейку `E2` каждой
  техкарты.
- На каждом листе-техкарте самостоятельно находит блоки «ТО‑1», «ТО‑2»,
  «ТО‑3», «ТО‑4» и ячейку «№ недели» рядом с ними, очищает старые
  значения и построчно вписывает актуальные номера недель (по
  возрастанию, без дублей).
- Ищет и озвучивает расхождения между «ППР» и техкартами, которые иначе
  остались бы незамеченными (см. раздел «Предупреждения» ниже).

**Чего не делает:**
- Не придумывает и не меняет сам график ТО на листе «ППР» — только
  переносит то, что там уже расставлено. Для автоматической генерации
  самого графика используется отдельный скрипт
  (`generate_ppr_schedule.py`), который должен отрабатывать раньше этого.
- Не создаёт новые листы-техкарты — только заполняет уже существующие.

## Что нужно установить

Требуется **Python 3** (проверялось на 3.9+) и библиотека **openpyxl**.

```bash
pip install openpyxl
```

Если `pip` недоступен напрямую (например, на Windows команда не
находится), попробуйте:

```bash
python -m pip install openpyxl
```

Проверить, что всё установлено:

```bash
python -c "import openpyxl; print(openpyxl.__version__)"
```

Никаких других зависимостей и доступа в интернет во время работы
скрипту не требуется.

## Как запустить

```bash
python fill_ppr_weeks_v2.py входной_файл.xlsx [выходной_файл.xlsx]
```

- **Один аргумент** (только входной файл) — результат сохраняется
  **поверх него же**. Перед первым запуском на реальном файле
  рекомендуется сделать резервную копию.
- **Два аргумента** — результат сохраняется в отдельный файл, исходный
  не меняется.

Пример:

```bash
python fill_ppr_weeks_v2.py ППР_2027.xlsx
```

или, чтобы не рисковать оригиналом:

```bash
python fill_ppr_weeks_v2.py ППР_2027.xlsx ППР_2027_заполнено.xlsx
```

Скрипт выводит в консоль отчёт: сколько листов обработано, какие
разделы найдены на «ППР», список предупреждений (если есть) и путь к
сохранённому файлу. Отчёт стоит читать целиком — именно там видно,
не «потерялись» ли какие-то данные.

## Требования к структуре файла

### Лист «ППР»
- Называется точно **«ППР»**.
- Есть строка с номерами недель (значения 1…53) — скрипт находит её
  автоматически, специально искать не нужно.
- Раздел оборудования начинается со строки, где в столбце **A** стоит
  целое число (1, 2, 3…, в том числе записанное текстом), а в
  столбце **B** — название раздела. Все строки ниже, вплоть до
  следующего такого числа, считаются относящимися к этому разделу
  (даже если в них пусто в столбце A или C — это нормально, например
  для строк-продолжений без отдельного адреса).
- Год указан где-то в ячейке `C1` в любом виде, где есть 4 цифры
  подряд (например «2027 год»).

### Листы-техкарты
- Название раздела указано в ячейке `C3` (обычно рядом подписано
  «Наименование:»). Оно должно **точно** (посимвольно, без лишних
  пробелов) совпадать с названием раздела в столбце B на листе «ППР».
  Если `C3` пустая — вместо неё используется название вкладки листа.
- В каждом листе есть заголовки «ТО‑1 (…)», «ТО‑2 (…)», «ТО‑3 (…)»,
  «ТО‑4 (…)» (текст в скобках не важен, важно, что строка начинается с
  «ТО‑1», «ТО‑2» и т.д.).
- Рядом с каждым таким заголовком, в пределах ближайших 6 строк ниже,
  должна быть ячейка с текстом, содержащим слово «недел» (например
  «№ недели») — именно её столбец скрипт использует для записи номеров
  недель. Не важно, находится ли эта ячейка в той же строке, что и
  заголовок «ТО‑N», или на строке ниже (вместе с первым пунктом работ)
  — скрипт распознает оба варианта и сам определит, с какой строки
  начинать запись значений.
- Под этой ячейкой должно быть после этого достаточно пустых строк,
  чтобы поместились все недели этого типа ТО за год (обычно с запасом
  хватает 6–12 строк).

## Как добавить новый раздел (новую техкарту)

Никаких изменений в коде не требуется:

1. Скопируйте существующий лист-техкарту как шаблон (сохранится вся
   нужная структура — заголовки «ТО‑N», ячейки «№ недели» и т.д.).
2. В ячейке `C3` впишите название раздела **точно** так, как оно
   записано в столбце B на листе «ППР» в строке-заголовке этого
   раздела — лучше скопировать текст оттуда, а не печатать вручную
   (лишний пробел или другая буква — и раздел не найдётся).
3. Запустите скрипт как обычно — новый лист обработается автоматически.

## Предупреждения — что они значат и как реагировать

Скрипт специально выводит **как можно больше** предупреждений, даже
если формально ничего не сломалось, — лучше лишний раз проверить, чем
пропустить реальную ошибку.

| Предупреждение | Что произошло | Что делать |
|---|---|---|
| «раздел … не найден на листе "ППР"» | Текст в `C3` техкарты не совпал ни с одним разделом на «ППР» | Проверить точное написание в `C3` (пробелы, регистр, опечатки) |
| «не найдены заголовки "ТО‑1"…"ТО‑4"» | На листе вообще не нашлось ни одного распознаваемого блока ТО | Проверить, что заголовки на листе начинаются именно с «ТО‑1», «ТО‑2» и т.д. |
| «найден заголовок "ТО‑N", но рядом… не найдена ячейка "№ недели"» | Заголовок есть, а подписи столбца для недель нет в пределах 6 строк — раздел НЕ будет заполнен | Добавить/поправить ячейку «№ недели» рядом с этим заголовком на самом листе |
| «в ППР для … есть ТО‑N…, но на техкарте нет раздела ТО‑N» | В графике запланированы работы этого типа, а блока для них на техкарте вообще нет | Добавить недостающий блок «ТО‑N» на техкарту либо проверить, что это не ошибка в самом графике |
| «есть раздел ТО‑N, но в ППР… не запланировано ни одной недели» | Блок на техкарте есть, но в этом году по нему нет работ — он останется пустым | Обычно это нормально (например, ТО‑2/ТО‑3 просто не предусмотрены для этого оборудования), но стоит перепроверить |
| «найдено N недель, а свободно только M строк» | Недель для этого типа ТО больше, чем места под них на техкарте | Освободить больше пустых строк под этим блоком на листе |
| «есть на листе "ППР", но не найден ни один лист-техкарта» | Раздел в графике есть, а техкарты под него вообще нет | Создать техкарту для этого раздела (см. раздел выше) |
| «на неделе N совпадают ТО‑2, ТО‑3…» | У ОДНОГО раздела в один и тот же месяц/неделю запланировано сразу два типа ТО (кроме ТО‑1, это нормально) | Проверить и поправить график на «ППР» — скорее всего, ошибка планирования |

«Всё прошло без предупреждений» означает, что структура файла и график
согласованы полностью — можно открывать техкарты и работать.

## Важно помнить

- Скрипт **детерминирован**: повторный запуск на одном и том же файле
  «ППР» даёт одинаковый результат и не создаёт дублей (старые значения
  всегда сначала очищаются, потом вписываются новые).
- Скрипт **не хранит формул** — только готовые числа. Это сделано
  специально: формулы с новыми функциями Excel (`FILTER`, `UNIQUE`,
  `SORT`) ненадёжно переживают открытие/«восстановление» файла в разных
  версиях Excel, а обычные числа — нет.
- Если структура файла сильно меняется (например, добавляются новые
  строки/разделы на «ППР» или меняется формат техкарт), стоит сначала
  прогнать скрипт на копии файла и внимательно прочитать все
  предупреждения, прежде чем использовать результат.
